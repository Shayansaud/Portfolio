- GitHub Pages

## Website Content
- About Me
- Skills

## Viewing the Website
Website link: https://Shayansaud.github.io/Portfolio/

To view the website locally, clone this repository using:

    git clone https://github.com/Shayansaud/Portfolio.git

Then open the Portfolio folder and double-click index.html to view it in a browser.
